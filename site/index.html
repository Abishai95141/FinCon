01

Adapter synthesis

A settlement file in a format we have never seen. The model reads twelve raw lines and authors the parse spec — delimiter, header row, minor units, a non-ISO date. It ingests with no configuration. The spec is data, never code: nothing a model writes is ever executed.

02

Classifying the tail ≈2.1s

The arithmetic names what it can first. Only what is genuinely unexplained is sent, with the near misses the engine derived. It comes back with a code, a hypothesis and cited evidence — and it declines when the files cannot separate two causes.

03

Rule induction

You resolve a break in your own words. The model proposes a deterministic rule that would have prevented it, regression-tested against every historical match before a named human approves it. Next month it fires as P1 RULE and nobody sees the item.

No model call in a close

The six-stage close makes zero model calls at any stage, and the receipt says so. Every match is arithmetic over raw records.

A proposal cannot overwrite a derived answer

A proposal is P2 at best and may not overwrite P0 ARITHMETIC. A derived item is never even offered — refusing after the call would still have spent it.

No generated code is executed

No eval, no exec, no dynamic import. Adapters are declarative specs read by a closed vocabulary of parse verbs; an unknown verb is a spec error, not an execution.

No tool carries authority

Not one of the 18 MCP tools accepts a policy, a tolerance, a sign convention or a rule set — checked against the generated schemas, because a convention lasts until the next person adds a tool.

Why FinCon

Built so you never have to take our word for it.

A reconciliation you cannot check is a reconciliation you cannot defend. Every claim below is enforced by a test that fails when it is violated — otherwise it is a preference, not a control.

Proof, not confidence

Every accepted match re-derives from raw records. A match without a passing proof is not counted. Match rates ship with their tier split, because a headline number alone is gameable — and gameable is indistinguishable from false.

It says when it does not know

Where two answers both fit the arithmetic, it returns the ambiguity rather than picking. Where nothing fits, it says so and hands you the evidence. Four of seven items in a real close are “I cannot say why”, and that number is printed rather than smoothed.

The tail is supposed to shrink

A resolution becomes a rule, regression-tested against every historical match and approved by name. The system gets more deterministic over time, not more agentic — which is the opposite of how agent products usually age.

Domain-agnostic, and measured

A second reconciliation — Form 26AS from the Income Tax Department against a TDS ledger — runs on the same engine with zero changes to it, asserted byte-for-byte. A generality that needed a change for its second instance was never a generality.
